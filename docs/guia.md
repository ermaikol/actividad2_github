¿Qué es Git?
Git es principalmente un sistema de control de versiones creado principalmente cuando Linus Torvalds (creador de Linux) estaba desarrollando el mismo y se encontraba con el problema de que tenía demasiado código y no podía probar nuevas funcionalidades por lo que creó este sistema para ello.

¿Qué es GitHub?
Principalmente una plataforma en la nube, algo así como un Git on-line, donde desarrolladores comparten sus proyectos y código

Direfencia entre repo local vs remoto
Principalmente la diferencia es que los repos locales únicamente se encuentran en la máquina donde son creados, por lo que si esos datos se pierden o les pasara algo, desaparecerían completamente, mientras que en remoto tanto tú con otro ordenador como otras personas pueden ver estos proyectos, descargarlos e incluso comentarlos o modificarlos a su gusto
